# 群关联监控惩罚插件 (astrbot_plugin_group_monitor) v1.5.0

监控群成员加群事件，如果在指定缓冲时间内未加入目标群，则自动在当前群执行禁言或踢出；加入目标群后自动解除监控群禁言。

## 新增特性 (v1.5.0)
- **时间单位支持“天/小时/分钟/秒”**：指令中的缓冲时间和禁言时长可直接写 `3天`、`1.5天`、`2小时`、`30分钟`、`60秒`；纯数字仍按秒处理，兼容旧用法。
- **列表与提示更易读**：规则列表、添加成功提示、入群提醒统一显示为“X天/X小时/X分钟/X秒”。

## 历史特性
- 规则别名与动态标题：WebUI 添加条目时可输入规则名称，外层卡片标题实时显示该名称（基于 `display_item`）。
- 禁言时长独立可配：支持自定义处罚禁言秒数。
- 加入目标群自动解除监控群禁言。

## 使用前提
- 机器人在**监控群（群1）必须是管理员**，否则无法禁言/踢出。
- 机器人在**目标群（群2）也建议设为管理员**。部分 NapCat/QQNT 环境下，机器人非管理员时目标群的新成员入群通知不会上报，导致“加入目标群自动解禁”无法触发。

## 指令说明（群主/群管理员/Bot管理员可用）
- `群监控帮助` / `群互联帮助`：查看指令帮助文档
- `添加群监控 <监控群> <目标群> [禁言/踢出] [缓冲时间] [禁言时长] [规则名称]`
  - 时间单位支持 `天`、`小时`、`分钟`、`秒`，纯数字按秒。
  - 例1：`添加群监控 111 222`（默认群号为名，禁言，缓冲60秒，禁言1天）
  - 例2：`添加群监控 111 222 踢出 10分钟 0 粉丝二群联动`（缓冲10分钟，踢出）
  - 例3：`添加群监控 111 222 禁言 1天 30天 临时禁言监控`（缓冲1天，禁言30天）
- `群监控列表`：查看当前所有规则名称、序号、惩罚方式与缓冲时间
- `删除群监控 <序号>`：删除指定序号的监控规则
- `设置惩罚 <序号> <禁言/踢出> [禁言时长或缓冲时间] [缓冲时间]`：调整已有规则的处罚方式及时间
  - 例：`设置惩罚 1 禁言 7天`（将规则1禁言时长设为7天）
  - 例：`设置惩罚 1 禁言 1天 2小时`（禁言1天，缓冲2小时）
